### ⚙️ Core Competencies

- **ETL/ELT pipeline development** — reliable workflows for structured and semi-structured data.
- **Real-time streaming** — event-driven ingestion and processing with Apache Kafka.
- **Data transformation and modeling** — dimensional models, incremental transformations, and data-quality checks.
- **Workflow orchestration** — DAG design, dependency management, retries, and backfills.
- **Financial data processing** — reconciliation-oriented data workflows and careful transaction-state handling.
- **Data warehousing and lakehouse** — PostgreSQL, Cassandra, and Delta Lake.
- **Observability and reliability** — pipeline metrics, logs, alerts, and data freshness checks.
- **Containerized development** — Docker-based local environments and cloud deployment workflows.
